---
title: "Getting Started"
---

A short, ordered path from a first launch to a recorded output. Read the four
pages in order.

1. [First Launch](01-first-launch/): the default layout, and what is
   already running before anything is configured.
2. [Load a Factory Patch](02-load-a-factory-patch/): confirming live output
   with zero configuration.
3. [Build a Custom Chain](03-build-a-custom-chain/): adding an effect and
   a second module to the default one-`OSC` starting chain.
4. [Record and Output](04-record-and-output/): getting a result out of the
   app, to a file or to another program.
