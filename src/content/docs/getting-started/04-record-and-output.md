## Save your pattern

Choose `File > Save As...` or press `Ctrl+Shift+S` (`Cmd+Shift+S` on
macOS). Save the animated patch as `First kaleidoscope.hxc`.

## Record a clip

Open `View > Settings` and select `Recording`. Choose H.264 and `30`
frames per second for this first clip. Check `Output Folder` before
recording so you know where the file will go.

Click `REC` in the main toolbar, let the pattern run for ten seconds,
then click `REC` again to stop.
Use `Ctrl+Alt+R` on Windows/Linux or `Cmd+Option+R` on macOS.

Recordings are saved as `hexcomposer_YYYYMMDD_HHMMSS.mp4` in the Movies
folder on macOS, the Videos folder on Windows, or the home folder on Linux.
A message shows the saved path when the file is complete. While the file
is being finalized, the timer shows `Saving...`.

Click the camera button beside `REC` to save a PNG in the same folder.
Use `PrintScreen` or `Ctrl+Alt+S` on Windows/Linux, or `Cmd+Option+S`
on macOS.

Recordings and snapshots contain the output image, without the app's panels
or letterbox bars.

Set quality, frame rate, codec, audio, and the save folder in
`Settings > Recording`.

Open the saved MP4 in a video player and check the animation before
recording a longer performance.

If recording fails or skips frames, see
[Troubleshooting](../../troubleshooting/).

## Send live output

To send output to another application, enable NDI, Spout (Windows), or
Syphon (macOS) in `Settings > Output`.

Related: [Output and Recording](../../concepts/output-and-recording/).
