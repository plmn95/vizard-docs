---
title: "Load a Factory Patch"
---

Open `File > Factory Patches`. Pick one, for example "Test Pattern 1953".
`Output` updates immediately: that's the whole patch, already running,
nothing left to configure.

Loading a factory patch fills the current slot without pointing Save at the
install directory. Press `Ctrl+S` afterward and it prompts for a save
location instead of silently overwriting the shipped file. Treat it as a
starting point, not a fixed reference copy.

The same list is available from a patch slot's own right-click menu, next to
`Reset to Default`.
