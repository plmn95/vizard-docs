---
title: "First Launch"
---

Launch Vizard. It opens into a working docked layout, not a blank window:
`Output` fills the center, `Module` sits in the panel on the right, and
`Chain` and `Patches` share one tabbed bar across the bottom. `Modulation`
is docked as a second tab beside `Module` but starts closed; open it from
`View > Modulation` and it lands there.

Expect `Output` to already show something. A first launch starts from one
default `OSC` module already in the chain, not an empty patch.

Mixer Mode has its own windows (`Mixer`, `Deck A`, `Deck B`, `Mixer Preview`).
They stay hidden until `F3` turns Mixer Mode on. Stay in the default,
non-Mixer layout for the rest of this section.
