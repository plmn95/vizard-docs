- [Reading the Panel](reading-the-panel/): identify Knobs, Troughs, Wheels,
  Pads, and the interface colors.
- [Signal Chain](signal-chain/): how modules combine into what `Output`
  shows.
- [Patches, Slots, and Banks](patches-slots-and-banks/): the `.hxc` file
  format and how slots and banks organize it.
- [Insert FX Chains](insert-fx-chains/): the per-module effect chain every
  module carries.
- [Modulation Matrix](modulation-matrix/): assigning modulation sources
  to parameters.
- [MIDI and OpenSoundControl Learn](midi-and-opensoundcontrol-learn/): the
  Learn-mode workflow shared by both input protocols.
- [AUX Sends and Buses](aux-sends-and-buses/): send a module's image to a
  bus and read it back with `INSERT` or `FEEDBACK`.
- [Chain Groups](chain-groups/): naming, color-tagging, collapsing, and
  multi-selecting a run of modules in `Chain`.
- [Mixer Mode](mixer-mode/): the two-deck live-performance mode.
- [Output and Recording](output-and-recording/): what leaves the app, and
  by which route.
- [Docking and Layout](docking-and-layout/): the dockable window system and
  its named layout presets.
