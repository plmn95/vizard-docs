---
title: "Docking and Layout"
---

Every window in Vizard docks freely: dragged, resized, tabbed together, or
closed, the same way across the whole app. `View` lists eight of them by
name, each with its own toggle: `Output`, `Chain`, `Patches`, `Module`,
`Modulation`, `Mod Matrix`, `AUX Buses`, and `Settings`. The
`Keyboard Shortcuts` window opens from `Help` and docks the same way, and
Mixer Mode's own set follows `F3` rather than a `View` entry.

The default arrangement docks `Output` centered, `Module` and `Modulation`
tabbed together on the right, and `Chain` and `Patches` tabbed together
across the bottom. Mixer Mode's windows share the same dockspace but stay
hidden until `F3` turns Mixer Mode on.

`View > Layouts > Save Layout As...` names and stores the current
arrangement; any saved layout appears above it in the same menu, ready to
reload with one click. `Restore Default Layout` discards whatever
arrangement is active and rebuilds the factory one from scratch, whether or
not it started from a saved layout.
