---
title: "Docking and Layout"
description: "Arrange Hex Composer windows by docking, resizing, tabbing, and using the View menu."
---

Windows can be docked, resized, or tabbed together. `View` opens `Output`,
`Chain`, `Patches`, `Module`, `Modulation`, `Mod Matrix`, `AUX Buses`, and
`Settings`. `Keyboard Shortcuts` opens from `Help`. Mixer Mode's windows
appear when Mixer Mode is enabled with `F3`.

`View > Layouts > Save Layout As...` saves a named layout. Saved layouts
appear in the same menu. `Restore Default Layout` restores `Output` in the
center, `Module` and `Modulation` on the right, and `Chain` and `Patches`
across the bottom.

Related: [Reading the Panel](../reading-the-panel/).
