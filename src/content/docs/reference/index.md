Lookup material. Each page documents one thing on its own; nothing here is
meant to be read start to finish.

- [Keyboard Shortcuts](shortcuts/): every bound key and mouse gesture, by
  scope.
- [Modules](modules/): the 9 module types a chain can contain.
- [FX](fx/): the 41-effect Insert FX catalog, by category.
- [Region](insert-fx-region/): the optional per-slot melt boundary any
  Insert FX slot can turn on, independent of the 41-effect catalog above.
- [Modulation](modulation/): the 9 modulation source families.
- [Windows](windows/): the non-module UI surfaces, Settings, Mod
  Matrix, and the rest.
