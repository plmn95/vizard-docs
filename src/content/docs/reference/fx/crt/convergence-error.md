---
title: "Convergence Error"
---

Offsets the R, G, and B channels independently, simulating a CRT tube whose
three electron guns don't quite land on the same spot.

| Parameter | Control | Range | Notes |
|---|---|---|---|
| R x / R y | Pad | -5 to 5px | |
| G x / G y | Pad | -5 to 5px | |
| B x / B y | Pad | -5 to 5px | |

Related: [Insert FX Chains](../../../../concepts/insert-fx-chains/).
