Effects available in each module's [Insert FX chain](../../concepts/insert-fx-chains/).
The picker's search field filters across categories. Each slot has a `Mix`
control in addition to the effect's parameters.

| Category | Members |
|---|---|
| [DISTORT](distort/) | Wave Warp, Kaleidoscope, Transform |
| [COLOR](color/) | Hue Rotate, Posterize, Dither, Palette Map, Threshold, Black & White, Invert |
| [FILTER](filter/) | Pixelate, Mask, Edge Detect, Edge Enhance |
| [RETRO](retro/) | VHS, Grain, Rutt-Etra |
| [CRT](crt/) | Scan Lines, Phosphor Mask, Vignette, Barrel, Glow, Convergence Error, Deflection Error, Persistence |
| [KEY](key/) | Luma Key, Chroma Key, Channel Select, Motion Key, Despill, Luma Range, Edge Key, Sat Isolate, Dominant Channel |
| [BLUR](blur/) | Gaussian Blur, Box Blur, Motion Blur, Radial Blur |
| [GRADE](grade/) | Channel Attenuverter, Channel Curves, Contrast, Saturation Adjust, White Balance |
