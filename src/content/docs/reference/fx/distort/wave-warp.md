---
title: "Wave Warp"
---

Displaces the image along a sine wave, independently on each axis.

| Parameter | Control | Range | Notes |
|---|---|---|---|
| Amp X / Amp Y | Pad | 0 to 0.1 | Displacement strength, read as one gesture. |
| Freq X / Freq Y | Pad | 0 to 20 | Wave frequency, read as one gesture. |
