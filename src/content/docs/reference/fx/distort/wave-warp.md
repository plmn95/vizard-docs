title: "Wave Warp"
description: "Displaces the image along a sine wave, independently on each axis."
---

Displaces the image along a sine wave, independently on each axis.

| Parameter | Control | Range | Notes |
|---|---|---|---|
| Amp X / Amp Y | Pad | 0 to 0.1 | Displacement strength. |
| Freq X / Freq Y | Pad | 0 to 20 | Wave frequency. |
