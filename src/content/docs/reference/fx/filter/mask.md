---
title: "Mask"
---

Cuts the image down to a soft-edged circle.

| Parameter | Control | Range | Notes |
|---|---|---|---|
| Center X / Center Y | Pad | -0.5 to 0.5 | |
| Radius | Trough | 0 to 1.5 | |
| Feather | Trough | 0 to 0.5 | Softness of the circle's edge. |

Related: [Insert FX Chains](../../../../concepts/insert-fx-chains/), [Region](../../../insert-fx-region/), which uses the same circular edge-and-feather boundary but lets slots merge together.
