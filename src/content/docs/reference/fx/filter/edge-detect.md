---
title: "Edge Detect"
---

Finds edges by local contrast (a Sobel filter) and draws only the
boundaries, discarding flat regions.

| Parameter | Control | Range | Notes |
|---|---|---|---|
| Sensitivity | Trough | 0 to 5 | |
| Threshold | Trough | 0 to 1 | |
