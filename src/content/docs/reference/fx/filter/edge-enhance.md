---
title: "Edge Enhance"
---

Sharpens the image by boosting contrast along detected edges, rather than
discarding everything else the way Edge Detect does.

| Parameter | Control | Range | Notes |
|---|---|---|---|
| Strength | Trough | 0 to 3 | |
| Radius | Trough | 0 to 10px | |
