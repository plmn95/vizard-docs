---
title: "Despill"
---

Removes leftover key-color spill from a subject after a chroma key,
without touching the matte itself.

| Parameter | Control | Options / Range | Notes |
|---|---|---|---|
| Spill Channel | Selector | Green Screen, Blue Screen | UI-only; not modulation-assignable. |
| Follow Chroma Key | Selector | Manual, Follow | UI-only. When set to Follow, automatically uses whichever [Chroma Key](../chroma-key/) sits in the nearest earlier slot on the same chain, instead of the manually chosen Spill Channel. |
| Strength | Trough | 0 to 1 | |

Related: [Insert FX Chains](../../../../concepts/insert-fx-chains/).
